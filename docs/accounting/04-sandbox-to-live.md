# bKash: sandbox থেকে live

গোপন মান (app key, secret, username, password) চ্যাটে, ইমেলে বা স্ক্রিনশটে দেবেন না। শুধু ওয়েব রুটের বাইরের `bmlhs-private-config.php`-তে, অথবা সার্ভারের এনভ্যারনমেন্টে।

প্রাইভেট কনফিগের আকার:

```php
'payment_gateways' => [
    'bkash' => [
        'base_url' => 'https://tokenized.sandbox.bka.sh/v2/tokenized-checkout',
        'app_key' => '',
        'app_secret' => '',
        'username' => '',
        'password' => '',
    ],
],
'payment_callback_base' => 'https://bmlhs.site/bmlhs',
```

এনভ্যারনমেন্ট ব্যবহার করলে নাম: `BMLHS_BKASH_BASE_URL`, `BMLHS_BKASH_APP_KEY`, `BMLHS_BKASH_APP_SECRET`, `BMLHS_BKASH_USERNAME`, `BMLHS_BKASH_PASSWORD`।

খালি `base_url` দিলে কোড স্যান্ডবক্স ঠিকানা নেয়। লাইভ ঠিকানা এই ফাইলে লেখা নেই — bKash যে ঠিকানা লিখে দেবে, সেটি বসাবেন।

## স্যান্ডবক্সে, লাইভের আগে

1. উপরের ক্রেডেনশিয়াল বসান। `payment_callback_base` দিন, যাতে কলব্যাক Host হেডারের উপর না দাঁড়ায়।
2. প্রধান শিক্ষক হিসেবে **অনলাইন পেমেন্ট** খুলুন। ব্যাজ `sandbox`। "প্রাইভেট কনফিগে যা নেই" খালি। মান পাতায় আসে না।
3. চার্জ কে বহন করবে ও হার (১০%-এর বেশি নয়) সেভ করুন। তারপর "অভিভাবক পোর্টালে চালু"।
4. একই পাতার cron কমান্ড cPanel-এ প্রতি ৫ মিনিটে দিন। CLI পথটি পছন্দনীয়। HTTP পথের `key` পাসওয়ার্ডের মতো; কাউকে পাঠাবেন না।
5. পাবলিক মেনুতে `https://bmlhs.site/bmlhs/fee-payment` যোগ করুন।
6. স্যান্ডবক্স ওয়ালেট দিয়ে একটি ছোট পেমেন্ট:
   - সফল: রসিদ হয়, bKash হিসাবে (১১৩০) টাকা ওঠে, চার্জ আলাদা।
   - বাতিল: রসিদ হয় না, অবস্থা বাতিল বা ব্যর্থ।
   - মাঝপথে ব্রাউজার বন্ধ: কয়েক মিনিটের মধ্যে cron মিলিয়ে সফল হলে রসিদ, না হলে ব্যর্থ/মেয়াদোত্তীর্ণ।
   - একই বোতাম দুবার: একটি রসিদ।
7. প্রথম সফল কলে bKash যদি Authorization হেডার না মানে, লগের ত্রুটি কোড দেখে কোড ঠিক করতে হবে। হেডারের ধরন অনুমান করে বদলাবেন না।
8. রিফান্ড: অফিসার আবেদন, প্রধান অনুমোদন। ৬০ দিনের মধ্যে, বাকি ফেরতযোগ্য টাকার বেশি নয়। ১১৩০ কমে।
9. সেটেলমেন্ট: অফিসার জমা, প্রধান যাচাই। ব্যাংক বাড়ে, bKash কমে। স্কুল চার্জ বহন করলে ৫১৬০-এ খরচ।

কোনো ধাপ না মিললে লাইভ করবেন না।

## লাইভ

1. bKash-এর প্রোডাকশন ক্রেডেনশিয়াল ও `base_url` প্রাইভেট কনফিগে বদলান। স্যান্ডবক্স মান মুছে ফেলুন।
2. পাতা রিলোড করে ব্যাজ `live` দেখুন। `sandbox` থাকলে ঠিকানা এখনো টেস্ট।
3. সবচেয়ে ছোট আসল পেমেন্ট করে রসিদ, খতিয়ান ও তারপর রিফান্ড মেলান।
4. Nagad চালু করবেন না। অ্যাডাপ্টার ডকুমেন্টেশন ছাড়া কিছু পাঠায় না।
